# CMI 9.8.7.5 — Restored Edition (work in progress)

Readable sources of CMI 9.8.7.5, recovered from `originals/CMI/CMI-9.8.7.5.jar` by decompilation with Vineflower 1.12.0 and repaired by hand. License: Apache-2.0 (as stated by the user).

## Status

- 1064 source files in `src/main/java`, all formatted with google-java-format 1.37.0.
- **973 files compile** against Paper 26.3 with CMILib. **91 files are listed in `excludes.txt`**: the original classes for them are used from the original jar.
  - 90 reference version-specific Minecraft internals (`net.minecraft.*`, `v1_*_R*` adapters in `NBT/`, packet and entity code). They need a server jar of each matching version, or a rewrite against the Paper API. This is not done.
  - 1 is `Modules/BlueMap/BlueMapManager.java`: the optional BlueMap integration. Its API stub (generated from bytecode) has a builder hierarchy that does not match the real API, so it is excluded instead of guessed.
- Compile-only stubs for optional plugin APIs (DiscordSRV, LuckPerms v2, Jobs, Citizens and others) are in `stubs/java`, generated by `tools/GenStubs.java`. They are not packaged and are not verified against the real plugins.
- `tools/VarTypes.java` and `tools/UsageTypes.java` restored generic types lost by the decompiler (raw `var`, usage-based type arguments). Compiler errors show where a guess was wrong.
- Runs on Paper 26.3 with CMILib: the log has no ERROR or SEVERE lines (one WARN about `EntityType.BLOCK_DISPLAY` in `CMIDisplay`). Only startup was tested; commands and features were not checked in game.
